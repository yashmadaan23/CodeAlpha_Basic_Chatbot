# 🤖 Basic Chatbot — Python

A simple **rule-based console chatbot** developed in Python as part of my **CodeAlpha Python Programming Internship**.

## 📌 Project Overview

This project is a basic command-line chatbot that interacts with the user through text-based conversations.

The chatbot responds to common user inputs using predefined rules and keywords. It provides simple responses to greetings, questions, and other basic interactions.

The project demonstrates the fundamentals of Python programming and simple chatbot logic.

## ✨ Features

- 🤖 Rule-based chatbot interaction
- 💬 Interactive console conversation
- 👋 Responds to common greetings
- 🗣️ Provides predefined responses
- 🔤 Handles user text input
- 🚪 Supports an exit command
- ⚡ Simple and beginner-friendly implementation
- 🐍 Built using basic Python concepts

## 🛠️ Technologies Used

- **Python 3**
- **VS Code**
- **Git & GitHub**
